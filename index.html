01 / vocabulário

As peças que fazem tudo funcionar.

Você não precisa decorar tudo. Comece entendendo como cada parte se conecta.

01

Repositório

A casa do seu projeto: arquivos, histórico, documentação e as regras do jogo em um só lugar.

02

Commit

Um registro pontual de mudança. Uma foto do projeto com contexto, autoria e intenção.

03

Branch

Uma linha de desenvolvimento independente para experimentar sem bagunçar a versão principal.

04

Pull request

O convite para revisar e conversar sobre uma mudança antes de incorporá-la ao projeto.

05

Issue

Um espaço para organizar tarefas, bugs, perguntas e ideias que merecem atenção.

06

Merge

O momento em que duas linhas de trabalho se encontram e uma contribuição entra no projeto.

02 / na prática

Do primeiro arquivo ao trabalho em equipe.

01

Você cria uma branch

Separe sua nova ideia da versão estável. É o seu espaço para construir.

02

Você faz commits

Registre o progresso em pequenas partes que façam sentido para quem lê.

03

O time revisa o pull request

Comentários, perguntas e sugestões tornam o código mais forte.

04

O merge fecha o ciclo

A mudança aprovada se junta ao projeto e fica disponível para todos.

03 / pronto para começar?

Seu próximo projeto merece um lugar para crescer.
